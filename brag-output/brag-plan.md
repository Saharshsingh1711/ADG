# 🛡️ ADG — Launch Video Creative Plan (`/brag`)

## 1. Project Summary & Identity

- **Project:** Autonomous Database Guardian (ADG)
- **Tagline:** Deterministic AI database interaction with Model Context Protocol (MCP) and Human-in-the-Loop review.
- **Design System:**
  - Base: `#0a0e17` (Deep Dark Slate)
  - Surfaces: `#101623` (Sidebar & Header), `#151d2e` (Cards & Tables), `#1b253b` (Elevated)
  - Text: `#f8fafc` (Primary), `#94a3b8` (Muted), `#64748b` (Dim)
  - Accents: `#3b82f6` (Primary Blue), `#10b981` (Safe Emerald), `#ef4444` (Hazard Red), `#f59e0b` (Warning Amber)
  - Typography: `Inter` + `JetBrains Mono`

## 2. Video Storyboard (20.0s, 60fps)

| Timestamp | Phase | Scene Description | On-Screen Action | Sound Cue |
|---|---|---|---|---|
| **0.0s – 3.5s** | **The Hook** | Welcome Screen & Instant Read Query | Cursor clicks *"List all registered users & roles"*. Thinking indicator pulses ➔ Instant table rendered with 11 user records. | Soft UI click + subtle data whoosh. |
| **3.5s – 11.0s** | **The Safety Gate** | Destructive Mutation Interception | Real-time typing in prompt: *"Delete all system logs where level = 'DEBUG'"*. LangGraph halts at Safety Gate. Approval card pops up. Cursor clicks `Approve (Y)`. | Typing click train + cautionary alert + affirmative approval chime. |
| **11.0s – 16.0s** | **The Telemetry** | Schema Tree & Audit Log | Sidebar tabs switch to Tables tree (11 users, 27 orders, 36 logs) and live Audit stream verifying the approved transaction. | Soft tab switch ticks + telemetry arpeggio. |
| **16.0s – 20.0s** | **The Outro** | Call to Action | Zoom out to minimalist product badge with GitHub clone command. | Warm chord cadence with reverberating tail. |
