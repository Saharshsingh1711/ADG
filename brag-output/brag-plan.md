# 🛡️ ADG — Launch Video Creative Plan (`/brag`)

## 1. Planning Rubric

- **Project Name:** Autonomous Database Guardian (ADG)
- **Tagline:** The AI Database Copilot that can't accidentally drop your production database.
- **Audience:** Backend engineers, database administrators, AI agent developers.
- **Core Value Proposition:** Decouples database tools via the Model Context Protocol (MCP) and enforces deterministic Human-in-the-Loop (HITL) physical interrupt gates for state-mutating queries.
- **Tone:** `cinematic` + `cyber-security` (Trailer-scale, high-velocity, glowing neon cyber-aesthetics).
- **Target Duration:** 20.0s (Landscape 1920×1080, 60fps).
- **Palette & Visual Identity:**
  - Obsidian Dark: `#060913`, `#0b1120`, `#111a30`
  - Neon Cyan Accent: `#00f0ff` (AI Reasoning & Safe Reads)
  - Hazard Crimson Accent: `#f43f5e` (HITL Safety Intervention Gate)
  - Emerald Safe: `#10b981` (Authorized Execution)
  - Typography: `Plus Jakarta Sans` & `JetBrains Mono`

## 2. Beat-by-Beat Storyboard

### Scene 1: The Nightmare (0.0s – 3.5s)
- **Visual:** Terminal prompt with an AI agent hallucinating: `DELETE FROM users WHERE 1=1;`.
- **Text Overlay:** *"What happens when your AI agent has direct SQL write access?"*
- **Motion:** Camera glitch, flashing red alert ring, rapid pulse.
- **Audio Cue:** Low resonant sub-bass drop + digital glitch alarm.

### Scene 2: The Armor — Enter ADG (3.5s – 8.0s)
- **Visual:** Cyberpunk shield slams onto screen with radial shockwave. The ADG Mission Control dashboard materializes with live telemetry HUD (MCP Stdio Online, Foreign Keys Enforced).
- **Text Overlay:** *"Autonomous Database Guardian. Hardcoded Runtime Guardrails."*
- **Motion:** Glassmorphic card cascade, glowing cyan border beam, live telemetry counter ticks.
- **Audio Cue:** Heavy mechanical impact slam + rising synthesizer riser.

### Scene 3: The Interception (8.0s – 14.0s)
- **Visual:** User inputs: `Delete all DEBUG system logs`. The 5-stage LangGraph execution pipeline animates:
  `MCP Schema ➔ LLM Planner ➔ [⚠️ SAFETY GATE INTERRUPT]`.
  The glowing hazard approval card pops up: `[Authorize Mutation (Y)]` vs `[Reject (N)]`.
- **Text Overlay:** *"Deterministic LangGraph State Machine. Mutating queries physically halt at runtime."*
- **Motion:** Glowing red radar pulse, cursor clicks `[Y] Authorize`, instantly shifts to Emerald Green execution.
- **Audio Cue:** High-voltage cyber lock sound ➔ affirmative confirmation chime.

### Scene 4: Instant Telemetry & Audit Trail (14.0s – 17.5s)
- **Visual:** Output data table with zebra striping slides in. Live audit log counter increments, showing query, timestamp, risk level, and operator signature.
- **Text Overlay:** *"Tamper-evident audit trail. Relational FK constraints. Zero accidental data loss."*
- **Motion:** Smooth horizontal sweep across audit stream and table stats.
- **Audio Cue:** Fast digital data telemetry arpeggio.

### Scene 5: Outro & Call to Action (17.5s – 20.0s)
- **Visual:** Central glowing shield logo with GitHub repository badge and live command:
  `git clone https://github.com/Saharshsingh1711/ADG.git`
- **Text Overlay:** *"You built it. Now protect it. ADG v2.4"*
- **Motion:** Dynamic zoom out with particle constellation and neon lens flare.
- **Audio Cue:** Cinematic orchestral final chord with reverberating tail.
