## Option 2: LinkedIn — Engineering Architecture Deep-Dive
Prompt guardrails are not enough to protect production databases from agentic hallucinations. 

I designed and open-sourced **Autonomous Database Guardian (ADG)** — a deterministic database interaction engine built with:
1. **Standardized Model Context Protocol (MCP)**: Server resources (`db://schema`) and decoupled read/write tool transports over stdio.
2. **LangGraph State Machine**: 5-node pipeline (`schema_fetcher` ➔ `planner` ➔ `safety_gate` ➔ `executor` ➔ `synthesizer`).
3. **Deterministic Safety Gates**: Mutating queries (`DELETE`, `DROP`, `UPDATE`) trigger runtime `interrupt()` tokens that can only resume through explicit operator approval.
4. **Mission Control Web Cockpit**: Real-time WebSocket streaming, schema tree inspector, and live audit stream.

Check out the demo and architecture: https://github.com/Saharshsingh1711/ADG
